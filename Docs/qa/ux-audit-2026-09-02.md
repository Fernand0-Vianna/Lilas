## 3. Bugs Encontrados

### BUG-001: Tags `<a>` aninhadas (Acessibilidade)
**Funcionalidade:** PostCard — feed e detalhe do post  
**Passo realizado:** Navegar pelo feed e inspecionar o HTML dos posts  
**Comportamento esperado:** Tags `<a>` válidas sem aninhamento  
**Comportamento encontrado:** O componente `PostCard` renderiza um `<Link>` (que gera `<a>`) dentro de outro `<Link>`, criando tags `<a>` aninhadas. Isso é HTML inválido e causa problemas para leitores de tela e navegação por teclado.  
**Evidência:** Console do navegador mostra erro `validateDOMNesting: <a> cannot appear as a descendant of <a>`  
**Severidade:** Alta  
**Reprodutibilidade:** Sempre  
**Arquivo:** `client/src/components/PostCard.jsx:169-177`

### BUG-002: Requisições N+1 na API (Performance)
**Funcionalidade:** Feed — carregamento de posts  
**Passo realizado:** Navegar para o feed e monitorar requisições de rede  
**Comportamento esperado:** Requisições em batch para likes, saves e poll_votes  
**Comportamento encontrado:** Cada post na lista dispara 2-3 requisições separadas para `likes`, `saves` e `poll_votes`. Com 20+ posts visíveis, isso gera 60+ requisições individuais.  
**Evidência:** Network requests mostra múltiplas requisições GET repetidas para cada post  
**Severidade:** Média  
**Reprodutibilidade:** Sempre  
**Arquivo:** `client/src/components/PostCard.jsx:82-88`

### BUG-003: Favicon ausente (404)
**Funcionalidade:** Geral — todas as páginas  
**Passo realizado:** Carregar qualquer página do site  
**Comportamento esperado:** Favicon exibido na aba do navegador  
**Comportamento encontrado:** Requisição para `/favicon.ico` retorna 404  
**Evidência:** Console mostra erro `Failed to load resource: the server responded with a status of 404 (Not Found) @ http://localhost:5173/favicon.ico`  
**Severidade:** Baixa  
**Reprodutibilidade:** Sempre

### BUG-004: Campo de email com valor pré-preenchido no login
**Funcionalidade:** Login — formulário de entrada  
**Passo realizado:** Acessar a página de login  
**Comportamento esperado:** Campos de email e senha vazios  
**Comportamento encontrado:** O campo de email já contém um valor parcialmente digitado ("jhonatanwillian2006@gm")  
**Evidência:** Snapshot mostra `textbox "seuemail@exemplo.com" [active] [ref=e13] [box=301,440,328,35]: jhonatanwillian2006@gm`  
**Severidade:** Média  
**Reprodutibilidade:** Sempre (possível estado persistido no browser)

### BUG-005: Dropdown de perfil sem fechar ao clicar fora
**Funcionalidade:** Topbar — menu do perfil  
**Passo realizado:** Clicar no avatar do usuário para abrir o dropdown, depois clicar fora  
**Comportamento esperado:** Dropdown fecha ao clicar fora  
**Comportamento encontrado:** O dropdown com "Meu perfil" e "Sair da conta" permanece aberto  
**Evidência:** Snapshot mostra o menu visível mesmo após navegação  
**Severidade:** Baixa  
**Reprodutibilidade:** Intermitente

### BUG-006: Botão "Buscar" no mobile abre busca mas sem input visível
**Funcionalidade:** Topbar mobile — busca  
**Passo realizado:** No mobile, clicar no botão de busca  
**Comportamento esperado:** Input de busca aparece e recebe foco  
**Comportamento encontrado:** O botão "Buscar" está presente mas não há input de busca visível no mobile (apenas no desktop)  
**Evidência:** Snapshot mobile mostra `button "Buscar" [ref=f5e7]` mas nenhum textbox de busca  
**Severidade:** Média  
**Reprodutibilidade:** Sempre

## 4. Análise por Página

### 4.1 Login (`/login`)

**Pontos positivos:**
- Layout limpo e centralizado
- Logo e tagline bem posicionados
- Botões "Entrar" e "Criar conta" com hierarquia visual clara
- Mensagem de privacidade na parte inferior
- Responsivo no mobile

**Pontos de melhoria:**
- Campo de email com valor pré-preenchido (BUG-004)
- Ausência de indicador de loading durante autenticação
- Mensagem de erro não testada (sem credenciais de teste)

### 4.2 Feed (`/`)

**Pontos positivos:**
- Cards de post com layout consistente
- Sistema de votação funcional
- Filtros "Em alta", "Novo", "Mais votado" visíveis
- Banner de emergência (Ligue 180) bem posicionado
- Scroll infinito com muitos posts carregados

**Pontos de melhoria:**
- Tags `<a>` aninhadas (BUG-001)
- Requisições N+1 (BUG-002)
- Posts de teste ("ASDFIEDHWT", "Teste magico") visíveis no feed
- Avatar fallback usa apenas a inicial (poderia ter cores diferentes por usuário)

### 4.3 Post Detail (`/post/:id`)

**Pontos positivos:**
- Layout claro com post + sidebar de comentários
- Sistema de votação funcional
- Seção de comentários com textarea e botão "Responder"
- Estado vazio "Nenhum comentário ainda." informativo
- Poll com percentuais e contagem de votos

**Pontos de melhoria:**
- Tags `<a>` aninhadas (BUG-001)
- Botão "Denunciar" posicionado no canto direito, pode não ser discoverable
- Sem indicador de loading ao enviar comentário

### 4.4 Comunidades (`/comunidades`)

**Pontos positivos:**
- Lista de comunidades com avatar, nome, membros e descrição
- Botão "Entrou" para gerenciar participação
- Input de busca para filtrar comunidades
- Layout limpo e organizado

**Pontos de melhoria:**
- Busca não tem debounce (pode gerar muitas requisições)
- Sem indicador de carregamento durante busca

### 4.5 Comunidade (`/c/:slug`)

**Pontos positivos:**
- Header da comunidade com nome, membros e categoria
- Botão "Sair" para deixar a comunidade
- Posts filtrados pela comunidade
- Sidebar "Sobre" com informações da comunidade

**Pontos de melhoria:**
- Sidebar poderia mostrar regras da comunidade
- Sem paginação (carrega todos os posts de uma vez)

### 4.6 Perfil (`/perfil`)

**Pontos positivos:**
- Header com avatar, nome, username, bio e data de entrada
- Stats: Posts, Karma, Comentários, Seguidores, Seguindo
- Tabs: Posts, Atividade, Salvos
- Sidebar "Sobre mim" e "Precisa de ajuda?"
- Botões "Editar perfil" e "Compartilhar perfil"

**Pontos de melhoria:**
- Avatar muito grande no desktop (96px conforme design system)
- Botão "Trocar foto de perfil" com ícone sobreposto ao avatar
- Sem preview de imagem ao trocar avatar

### 4.7 Criar Post (`/criar`)

**Pontos positivos:**
- Seleção de comunidade com chips
- Tabs: Publicação, Link, Enquete
- Campos de título e corpo bem definidos
- Tags de contexto opcionais
- Mensagem "Sua publicação é anônima e pode salvar vidas"

**Pontos de melhoria:**
- Sem validação client-side visível (título obrigatório não indicado)
- Botão "Publicar" não desabilita durante envio
- Sem preview do post antes de publicar
- Adicionar foto sem preview da imagem selecionada

## 9. Riscos Identificados

1. **Dados de teste no feed:** Posts como "ASDFIEDHWT" e "Teste magico" estão visíveis para usuários reais
2. **Performance em mobile:** Muitas requisições de rede podem causar lentidão em conexões lentas
3. **Acessibilidade:** Tags `<a>` aninhadas podem impedir uso por leitores de tela
4. **Favicon ausente:** Pode causar impressão de site incompleto
