# Contribuindo

Obrigado pelo interesse em contribuir com o Lilás! Este é um projeto acadêmico focado no Agosto Lilas.

## Como Contribuir

1. **Fork** o repositório
2. Crie uma **branch** para sua feature: `git checkout -b feature/nova-funcionalidade`
3. **Commit** suas mudanças: `git commit -m 'feat: adiciona nova funcionalidade'`
4. **Push** para a branch: `git push origin feature/nova-funcionalidade`
5. Abra um **Pull Request**

## Convenções de Código

- **Linguagem:** JavaScript (ES modules)
- **Framework:** React 18
- **Estilo:** CSS puro com variáveis CSS customizadas
- **Commits:** Use mensagens descritivas em português
- **Arquivos:** Componentes em `PascalCase`, hooks/utils em `camelCase`

## Estrutura de Pastas

```
client/src/
├── lib/           # Clientes Supabase, auth, utilitários
├── pages/         # Páginas da aplicação
├── components/    # Componentes reutilizáveis
└── styles.css     # Estilos globais e tokens
```

## Antes de Abrir PR

- [ ] O build passa (`npm run build`)
- [ ] O código segue o estilo existente
- [ ] Variáveis sensíveis não são commitadas
- [ ] A documentação foi atualizada se necessário

## Código de Conduta

- Respeite todas as pessoas
- Ambiente seguro e inclusivo para mulheres
- Não compartilhe informações pessoais de outros
