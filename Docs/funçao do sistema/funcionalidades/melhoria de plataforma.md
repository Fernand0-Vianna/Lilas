## 🚀 Sugestões de Melhorias Pós-MVP

### 🛡️ Segurança e Privacidade
* [ ] **Botão SOS / Saída Rápida**: Botão visível para redirecionar instantaneamente a página para um site neutro (ex: busca do Google ou portal de notícias).
* [ ] **Limpeza de Histórico Local**: Opção para apagar dados de navegação local e cache diretamente pelo perfil.
* [ ] **Criptografia de Mensagens/Relatos**: Proteção ponta a ponta em envios confidenciais.

### 👥 Comunidade e Engajamento
* [ ] **Pesquisa Avançada**: Filtros para buscar conteúdos por tags, intervalo de datas ou comunidades específicas.
* [ ] **Notificações em Tempo Real**: Alertas no app para respostas em posts, novos seguidores e atualizações de status.
* [ ] **Postagens Salvas em Pastas**: Organização de posts favoritos por categorias personalizadas.
* [ ] **Fixar Publicações**: Opção para administradores fixarem avisos e materiais importantes no topo das comunidades.

### 📋 Módulo de Relatos e Apoio
* [ ] **Acompanhamento por Protocolo**: Sistema para a usuária acompanhar o andamento de um relato via código único.
* [ ] **Mapeamento Geográfico de Apoio**: Mapa interativo com localização de DEAMs, CRAS, CREAS e defensorias públicas próximas.
* [ ] **Anexo de Evidências Otimizado**: Suporte para upload seguro de áudios, vídeos e documentos.

### 🎨 Experiência do Usuário (UX/UI) & Performance
* [ ] **Modo Escuro (Dark Mode)**: Alternância de tema para maior conforto visual.
* [ ] **Acessibilidade (a11y)**: Leitor de tela aprimorado, alto contraste e atalhos de teclado.
* [ ] **Migração para TypeScript**: Tipagem estática do código frontend para reduzir erros em produção.
* [ ] **PWA (Progressive Web App)**: Permitir instalação do sistema na tela inicial do celular sem precisar de lojas de aplicativos.
